Owner: Web presentation; утверждает пользователь.
Общий журнал UI-решений: Demo P0–P3 и переход к модернизации production.
Нормативные границы — в [UI Architecture](UI_ARCHITECTURE.md); здесь история согласований.

Статусы: `Proposed`, `In Review`, `Approved`, `Superseded`, `Open Decision`.
`Approved` требует явного согласия; молчание и удачный browser-check им не являются.
`Completed` обозначает только технический checkpoint, не согласование дизайна.

### S2a model selection — 2026-11-02

Approved scope: «Это надо исправить» — выбор модели для Workspace; «Возможности
должны быть одинаковы для чата не зависимо от типа. Не плоди дубли» — общий UI и
общие владельцы поведения. Реализация picker/preferences и applied/draft boundary
зафиксирована в canonical documents; её визуальный статус **In Review**. Это
явный предметный scope, не автоматический переход к P4 или утверждение остальных S2.

### Единый чат целиком — уточнение 2026-11-02

Approved requirement: «весь чат единый и все его возможности, разница лишь в
сервисах инструментах и прочих внутренних отличиях». Общие controls/DOM S1a/S1b
и model slice S2a не означают завершения общего чата. Независимые Chat View пока
не реализованы. Целевая ownership-граница и остаток S2 уточнены в Architecture
и Migration Plan; новых визуальных решений это согласование не утверждает.
