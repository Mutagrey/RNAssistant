# Решения по новому визуальному прототипу

Owner: Demo presentation (`prototypes/ui/`); утверждает пользователь.
Журнал относится только к новой фазе от 2026-11-01. Поддерживать до передачи
утверждённого прототипа в отдельно разрешённую production-фазу; при замене
перенести решения в её canonical document и обновить ссылки.

Статусы: `Proposed`, `In Review`, `Approved`, `Superseded`, `Open Decision`.
`Approved` требует явного согласия; молчание и удачный browser-check им не являются.
