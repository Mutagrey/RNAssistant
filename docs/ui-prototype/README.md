# RNAssistant Visual Prototype — Agent Package

Give the agent the whole package and ask it to begin with `00_START_HERE.md`.

Files:
- `00_START_HERE.md`: scope, phases, gates and definition of done.
- `01_PROTOTYPE_UX_SPEC.md`: shell, Dockview and view scenarios.
- `02_DESIGN_RULES.md`: visual tokens, component reuse and portability.
- `03_DOCUMENTATION_WORKFLOW.md`: when and how to maintain UI specs.
- `04_AGENTS_MD_SNIPPET.md`: safe integration into existing AGENTS.md.

This package does not replace the previously prepared full RNAssistant UI architecture and migration document. Use that only after the visual prototype is approved and the user explicitly authorizes production work.
