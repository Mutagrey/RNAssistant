# Проверка RNAssistant на Windows/Office

Разработка ведётся на macOS без Office. Пользователь собирает и проверяет результат
на отдельной реальной машине с Windows и Office. Это прямой путь проверки продукта:
никакой отдельный процесс, helper или набор встроенных проверок не запускается.

Qualification Center, его packs, runner, bridge API и Excel identity helper удалены.
Ранее записанные `qualification.*` события остаются в существующих чатах и могут
читаться как исторические записи; новые runs такого типа не создаются. Никакие
чаты, события или VBA journals при удалении функции не стираются.

В обычной разработке проверяются только изменённые контракты в объёме, выбранном
для конкретной задачи. Отсутствие Windows/Office на Mac не делает рабочий baseline
недоступным, но результаты локальных проверок нельзя выдавать за проверку COM,
VSTO или WebView2. Для формального релиза evidence конкретной Windows сборки и
оставшиеся риски фиксируются по [процессу релиза](operations/RELEASE_PROCESS.md),
[PROGRESS](stabilization/PROGRESS.md) и [RISK_REGISTER](stabilization/RISK_REGISTER.md).

## Диагностика

В интерфейсе есть три маршрута:

- **Ход работы** — короткие сообщения текущего сеанса; экран хранит только последние
  500 строк и не опрашивает ничего в фоне.
- **История чата** — сохранённые шаги запуска в порядке выполнения. Поиск, исходные
  события и узкие технические представления доступны по запросу. Большие тела
  событий читаются только при открытии записи.
- **Проверки и данные** — ручная проверка связи с моделью, обслуживание CAS и
  осознанный сброс данных.

Дифф текущего кода смотрят во вкладке VBA. Сохранённый VBA mutation journal остаётся
источником восстановления и доказательством результата записи; его технические
записи доступны в расширенной истории чата.

## История решения

Прежний проект встроенной квалификации описан в
[ADR-0010](decisions/ADR-0010-qualification-evidence-authority.md) и WQ reports.
Эти документы объясняют удалённое решение и не задают текущий пользовательский
маршрут.

## 11. Phase 11 Issue Center

Предложенный Issue Center также не входит в текущий интерфейс. Сохранённые
события открываются через историю чата и causal detail без отдельного списка
проблем или второго хранилища результатов.
