# VS Code split icons

Owner: Web presentation. Two original Codicons by Microsoft and contributors:
`split-horizontal.svg` (area to the right) and `split-vertical.svg` (area below).

Source: [microsoft/vscode-codicons](https://github.com/microsoft/vscode-codicons),
commit `ceaa8663a7e63e2bac7f1ecac128ce31404b7487`.
Licensed under [Creative Commons Attribution 4.0](LICENSE).
The SVG files are unmodified; The shared Shell applies a CSS mask for theme color.
[provenance.json](provenance.json) records pinned URLs and SHA-256 hashes.

No icon font or library is installed. Both SVGs load locally. Remove this directory
when no Shell or reference Demo consumer remains.
