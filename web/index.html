Как работают инструменты RNAssistant

        
      

      

        

          
Работа с чатом

          
В Agent mode можно описывать нужный результат обычным языком. Модель возвращает JSON-блоки RNAssistant для действий с документом, а RNAssistant выполняет их, если включен автозапуск.

          
Создай новый лист Sales Demo, сгенерируй данные продаж по месяцам и построй линейный график.

        

        

          
Формат агента

          
Модель должна вернуть один fenced-блок rnassistant-agent. RNAssistant читает toolId/tool/action/name и параметры arguments/args/parameters.

          
```rnassistant-agent
{"description":"Создать демо продаж","steps":[
  {"description":"Добавить лист","toolId":"excel.add_sheet","arguments":{"name":"Sales Demo"}},
  {"description":"Записать данные","toolId":"excel.write_table","arguments":{"sheet":"Sales Demo","startAddress":"A1","values":[["Month","Sales"],["Jan",120]]}},
  {"description":"Построить график","toolId":"excel.add_chart","arguments":{"sheet":"Sales Demo","sourceRange":"A1:B2","chartType":"line","title":"Sales"}}
]}
```

        

        

          
Работа с tools

          
Откройте Tools, выберите tool и проверьте его schema, pipeline, VBA-код и заметки. Для custom tools и skills сначала используйте Dry Run, затем Run. VBA-код агента должен соответствовать текущему Office host.

        

        

          
Переиспользуемые tools

          
Custom tools хранятся в %AppData%\RNAssistant\tools. Pipeline tools последовательно вызывают существующие tools. VBA tools хранят редактируемый код в code.vba.

        

        

          
Markdown skills

          
Skills - это файлы-инструкции из %AppData%\RNAssistant\skills. Они помогают агенту выбрать подход, но исполняемые действия все равно выполняются через tools.

        

        

          
Работа с VBA

          
На вкладке VBA можно загрузить модули Office VBA, редактировать код, смотреть diff, сохранять изменения с автоматическим backup и восстанавливать backup. Переключатель VBA в Chat добавляет проект в контекст активного чата.

        

        

          
Настройки безопасности

          
Настройки управляют таймаутом запросов, автозапуском read-only tool calls, повтором после ошибок и тем, могут ли изменения документа/VBA выполняться без ручного подтверждения.
