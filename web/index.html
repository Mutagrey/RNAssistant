Возможности моделей

                      
Каталог может содержать только ID. Остальные поля задаются вручную; пустой контекст использует безопасный резерв 32768 токенов.

                    

                  

                  

                

                

                  

                    

                      
Маршрутизация вложений

                      
Если модель чата сама поддерживает Vision/Audio, она получает media напрямую одним запросом. Для недостающих модальностей helper видит только текущий запрос и файлы.

Выполнение

                  
Подтверждения, сжатие контекста и предельные значения одного запуска.

                

                

                  
                  
                  
                  
                  
                

                
Agent получает tools и каталог skills в RUNTIME_CONTEXT. Независимые вызовы выполняются последовательно за один model turn; зависимые и требующие подтверждения выбираются по одному.

Защита

                
Экранное содержимое и локальная история чатов.

              

              

                

                  

                    
Защита экрана

                    
Для отдельного окна RN Assistant, запущенного через NativeHostCli.

                  

                

                
                
Настройка применяется сразу: совместимые средства захвата увидят окно Office под ассистентом. VSTO-панель является частью окна Office и этой настройкой не защищается. Это не защита от камеры или привилегированного ПО.

              

              

                

                  

                    
Защита истории

                    
По умолчанию история остаётся незашифрованной с обычной SHA-256 hash chain.

                  

                

                

                  
                  
                  
                  
                

                
HMAC подтверждает целостность, но не скрывает содержимое. Шифрование использует AES-256-CBC + HMAC-SHA256; envelope событий остаётся видимым. Режим или ключ меняются только после «Очистить данные».

              

            


            

              

                
Диагностика

                
Проверки runtime, канонические JSONL-журналы и производные представления.

              

              
              

                
                
                
                
                
              


              

                

                  
События JSONLНеизменяемый источник истины: точные записи session stream с hash chain.

                  
ТраекторияВременная проекция из проверенных событий: связывает turns, model steps, tools и версии артефактов.

                  
VBA journalОтдельный document-scoped JSONL-журнал мутаций модулей и пакетов с before/intended source в CAS.

                

                

                  

                    

                      
Связь с моделью

                      
Один короткий запрос с текущими настройками. Фоновые проверки не выполняются.

                    

                    
                  

                  

                

                

                  

                    

                      
Хранилище CAS

                      
Проверяет ссылки из всех chat streams и VBA journals. Удаляются только доказанные orphan blobs.

                    

                    

                      
                      
                    

                  

                  

                

                

                  

                    
Сброс локальных данных

                    
Удаляет чаты, контекст, резервные копии VBA и кеш WebView.

                  

                  
                

              


              

                

                  

                    
События JSONL

                    
Канонические записи активного chat stream. Event data показан сразу, большие payload читаются из CAS только по запросу.

                  

                

                

                  
                  
                  
                  
                  
                  
                  
                

                

                
Нажмите «Обновить», чтобы прочитать текущий event stream.
