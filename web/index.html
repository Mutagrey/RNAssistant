How RNAssistant tools work

        
      

      

        

          
Chat workflow

          
Ask for the Office result in normal language. The model sees enabled tools, returns tool calls, and RNAssistant executes them when auto-run is enabled.

          
Создай новый лист Sales Demo, сгенерируй данные продаж по месяцам и построй линейный график.

        

        

          
Tools workflow

          
Open Tools, select a tool, inspect its schema, pipeline, VBA code, and notes. Use Dry Run before Run for custom tools.

        

        

          
Reusable tools

          
Custom tools are stored in %AppData%\RNAssistant\tools. Pipeline tools call existing tools in order. VBA tools store editable code in code.vba.

        

        

          
VBA workflow

          
Use the VBA tab to load Office VBA modules, preview diffs, save module changes with automatic backup, and restore backups. Enable VBA context in Settings only when chat needs existing VBA code.

        

        

          
Safety switches

          
Settings controls whether LLM tool calls auto-run, retry after errors, and whether tools marked Requires confirmation can run without manual Run.
