How RNAssistant tools work

        
      

      

        

          
Chat workflow

          
With Agent mode enabled, ask for the Office result in normal language. The model must return RNAssistant JSON tool blocks for document actions, and RNAssistant executes them when auto-run is enabled.

          
Создай новый лист Sales Demo, сгенерируй данные продаж по месяцам и построй линейный график.

        

        

          
Agent format

          
Models should return one fenced rnassistant-agent block. RNAssistant parses skillId/toolId/tool/action/name plus arguments/args/parameters.

          
```rnassistant-agent
{"description":"Create sales demo","steps":[
  {"description":"Add sheet","skillId":"excel.add_sheet","arguments":{"name":"Sales Demo"}},
  {"description":"Write data","skillId":"excel.write_table","arguments":{"sheet":"Sales Demo","startAddress":"A1","values":[["Month","Sales"],["Jan",120]]}},
  {"description":"Create chart","skillId":"excel.add_chart","arguments":{"sheet":"Sales Demo","sourceRange":"A1:B2","chartType":"line","title":"Sales"}}
]}
```

        

        

          
Tools workflow

          
Open Tools, select a tool, inspect its schema, pipeline, VBA code, and notes. Use Dry Run before Run for custom tools. Agent VBA code should be written as VBA for the current Office host.

        

        

          
Reusable tools

          
Custom tools are stored in %AppData%\RNAssistant\tools. Pipeline tools call existing tools in order. VBA tools store editable code in code.vba.

        

        

          
VBA workflow

          
Use the VBA tab to load Office VBA modules, preview highlighted code, save module changes with automatic backup, and restore backups. Use the VBA toggle in Chat to attach the project as active chat context.

        

        

          
Safety switches

          
Settings controls request timeout, whether read-only LLM tool calls auto-run, retry after errors, and whether document/VBA mutations can run without manual confirmation.
